# ✅ To-Do List

Lista de tarefas simples e funcional com **persistência em localStorage**,
desenvolvida com HTML, CSS e JavaScript puro.

## 🎯 O que faz

- Adicionar, concluir e remover tarefas
- Contador de pendentes
- Persistência automática no navegador (localStorage)
- Limpar concluídas / limpar tudo (com confirmação)
- Interface responsiva

## 🚀 Como rodar

1. Abra o arquivo `index.html` no navegador (ou sirva a pasta com `npx serve`).

## 🧠 O que aprendi

- Persistência com `localStorage` (JSON parse/stringify com tratamento de erro)
- Renderização declarativa a partir de estado (`todos` + `render()`)
- Delegação de eventos por elemento dinâmico
- Acessibilidade: checkbox com `aria-label` dinâmico e foco visível
