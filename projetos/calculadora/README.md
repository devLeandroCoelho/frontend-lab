# 🧮 Calculadora

Calculadora web responsiva com as 4 operações básicas, desenvolvida com
HTML, CSS e JavaScript puro (sem dependências).

## 🎯 O que faz

- Adição, subtração, multiplicação e divisão
- Porcentagem, limpar (C) e apagar último dígito (⌫)
- Suporte ao **teclado** (dígitos, `Enter`, `Esc`, `Backspace`, operadores)
- Tratamento de divisão por zero
- Interface responsiva (mobile e desktop)

## 🚀 Como rodar

1. Abra o arquivo `index.html` no navegador (ou sirva a pasta com `npx serve`).

## 🧠 O que aprendi

- Manipulação de DOM e eventos (clique e teclado)
- Estado da calculadora (operando atual, anterior e operação pendente)
- Formatação de resultados com precisão flutuante (`toPrecision`)
- Acessibilidade básica: `aria-live` no display e foco visível nos botões
